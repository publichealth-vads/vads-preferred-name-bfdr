Documentation

This browser was generated from the supplied PHIN VADS bulk export archive. It includes value sets referenced by BFDR-related PHIN VADS Messaging Guide Views and preserves the historical fields as represented in that archive.

Assignment workflow

  1. Search the historical VADS value-set directory by name, OID, value-set code, definition, or partial text; alternatively allow the browser to suggest a source from concept overlap.
  2. Upload the current VSAC value-set export. The browser reads the Expansion List and, for VSAC Excel/Grouping ZIP files, updates the current VSAC value-set metadata from the workbook.
  3. Confirm the detected VSAC metadata and the column mapping for Concept Code, Concept Name, and Code System OID.
  4. Add the maintaining organization/jurisdiction and optional instructions for users.
  5. Compare the current VSAC concept name with the historical VADS Concept Name and Preferred Concept Name.
  6. Retain or edit the Preferred Concept Name for the maintaining CDC program or jurisdiction. Add optional concept comments or value-set-level user instructions when useful.
  7. Choose the columns needed for distribution, then export either JSON or a VADS legacy Excel workbook with separate Value Sets Header and Expansion List worksheets.

Export formats and column selection

The VADS legacy download uses the historical VADS concept-table structure: Concept Code, Concept Name, Preferred Concept Name, Code System OID, Code System Name, Code System Code, Code System Version, HL7 Table 0396 Code, and Preferred Alternate Code when available. The current VSAC Concept Name and current code-system version are used where available.

When comments & provenance is selected, the VADS concept columns remain first and the browser can append concept-level historical names, Preferred Name Source, match information, optional comments, and update timestamp. Value-set-level VSAC metadata, Preferred Value Set Name Comments, PHIN VADS lineage, maintainer/jurisdiction, user instructions, and timestamps are kept on the separate Value Sets Header worksheet rather than repeated on every concept row. Preferred Name Source is reported as PHIN VADS, Maintainer Assigned, or No Preferred Name.
